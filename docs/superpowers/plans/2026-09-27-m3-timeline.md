# M3 — Timeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. See "Execution and checkpoints" below: this plan recommends a split, not one mode for everything.

**Goal:** Read the Micro.blog timeline newest-first, scroll back a few hundred posts smoothly, and
see new posts arrive behind an "N new posts" pill without losing your place — `docs/milestones.md`
M3, story U4.

**Architecture:** Task 1 is a spike that settles SPEC §12 Q2 (native `RichTextBlock` converter vs
one WebView2) with measurements on real posts; the human partner approves the choice before
anything is built on it. Tasks 2–7 are WinUI-free and live in `Transom.Core` (tested on Linux too):
JSON Feed DTOs and `TimelineClient`, `ITimelineProvider`, a pure `TimelineBuffer` that owns paging
and new-post state, poll scheduling and back-off, relative times, an HTML → `RichContent` parser,
and an LRU index for the image cache. `Transom.App` adds a disk image cache, `TimelineViewModel`
(no WinUI types), and a `TimelinePage` whose `ListView` renders `RichContent` into `RichTextBlock`s.
This plan is written for the converter path (SPEC's planned default). If the spike picks WebView2,
Tasks 6, 7 and 10 get rewritten at Checkpoint 1 before any of them runs. Tasks 2–5, 8 and 9 stay
as written.

**Tech Stack:** .NET 10, `System.Text.Json` source generation, `Microsoft.Extensions.Http`,
HtmlAgilityPack (Core), CommunityToolkit.Mvvm, `TimeProvider` +
`Microsoft.Extensions.TimeProvider.Testing` (App tests), WinUI 3 `ListView`/`RichTextBlock`,
`Windows.System.Launcher`, xUnit + fake `HttpMessageHandler`s.

**Spec:** `SPEC.md` §3 (U4), §4.1 (main window, timeline item layout and behaviours), §5
(architecture, `ITimelineProvider`), §6.3 (JSON API, pagination, rendering), §6.4 (rate limits,
User-Agent), §8 (image cache in `LocalCacheFolder`, 200 MB LRU), §10 (quality bar), §12 Q2.
`docs/milestones.md` M3. Tracking issue: **#6**. Branch: `m3-timeline`.

## Global Constraints

- Never log, print, persist or commit tokens (CLAUDE.md Rule 1). The spike's captured timeline
  JSON contains other people's posts. It stays in the app's `LocalFolder` and is **never
  committed**. Test fixtures are hand-written from its *shape* with invented people and URLs
  (Rule 2).
- **The image cache never sends the Micro.blog token.** Avatars and photos are fetched through a
  separate named `HttpClient` (`"images"`) that has no `Authorization` header. Only Micro.blog API
  calls carry the bearer token.
- No real network calls in tests (Rule 2). Fixtures go in `tests/Transom.Core.Tests/Fixtures/`.
- Provider-specific code stays in `Core/Providers/MicroBlog/`. View models talk to
  `ITimelineProvider` only (Rule 3).
- Every async method takes a `CancellationToken`. No `.Result`/`.Wait()` (Rule 4). The one
  deliberate exception is documented in Task 7: the shared image download runs on `None`, and each
  caller waits on it with its own token.
- View models have no WinUI types (Rule 5). Launching a URI and writing the clipboard go through
  `ILinkOpener`/`IClipboardService` in `Transom.App/Services`.
- Every interactive control gets `AutomationProperties.Name`, and the timeline is fully keyboard
  navigable (Rule 7).
- Rules 11 and 12: every `async void` handler and every `[RelayCommand]` body catches at its entry
  point, reporting through an InfoBar and the logger. `App.OnUnhandledException` is never relied on.
  Expected cancellation is handled where it's known to be expected. **Tests await the task itself,
  never through `Task.WhenAny`.**
- `x:Bind` never sets `DataContext`: item-template click handlers read `Tag="{x:Bind}"` (CLAUDE.md
  Style). `x:Bind` never converts `string` to `ImageSource`: images load through the `CachedImage`
  attached property in Task 10, which treats null, empty and whitespace URLs as "no image". That
  URL shape is the one that crashed M1.
- SPEC §6.4: poll no more often than every **60 s** (default **2 min**); back off exponentially on
  429/5xx; send `User-Agent: Transom/<version> (+https://github.com/amatern/transom-microblog)`.
  The existing named/typed clients already set it, and `"images"` must too.
- Theme: no hard-coded colours. Rendered post text uses only theme-inherited brushes, so switching
  Windows light/dark while the app runs re-colours everything.
- One commit per task, referencing **#6**. Every task's last step before committing is
  `dotnet format Transom.sln --verify-no-changes`. Rule 10: an interface change updates every
  implementation and test double in the same commit.

## What has no automated coverage (and how it's checked instead)

M3 is mostly view layer, and this repo has no WinUI test harness. Here is what the automated tests
**cannot** see:

| Area | Why it isn't automated | Checked by |
|---|---|---|
| Spike measurements (fidelity, FPS, memory, cold start) | Needs a real window, real posts, a real GPU | Task 1, repeatable scripted measurements + Checkpoint 1 |
| `RichContentRenderer` (RichContent → `RichTextBlock`) | `RichTextBlock` can't be created outside a XAML thread | M-3, M-5 |
| `TimelinePage` XAML: item template, footer, pill placement, empty/sign-in states | XAML | M-1, M-2, M-4, M-7, M-8 |
| Near-bottom trigger for loading older posts | Depends on the `ScrollViewer` inside `ListView` | M-2 |
| Scroll position not jumping when new posts arrive | `ListView` behaviour; the VM guarantees the poll never mutates `Items`, which *is* tested | M-4 |
| `CachedImage` attached property (recycling, decode size, placeholders) | Needs XAML + real `BitmapImage` decode | M-6, M-9 |
| Image viewer dialog | `ContentDialog` | M-10 |
| `LauncherLinkOpener`, `ClipboardService` | WinRT; the VM commands that call them are tested against fakes | M-11 |
| Narrator, keyboard navigation, high contrast, text scaling, light/dark | Assistive tech + OS settings | M-12, M-13 |
| Smoothness with 200–1,000 items; memory; cold start | Performance | M-14 |
| Real-server semantics of `since_id` / `before_id` at the end of a feed | No real network in tests | Task 1 records them in SPEC §6.3; tests encode what was recorded |

The automated suite covers the logic those surfaces sit on: the JSON client and mapper, the paging
buffer, poll scheduling, relative time, the HTML parser, the LRU index, the disk cache (temp folder
plus fake handler), and both timeline view models. **No test in this plan exists only to prove a
fake was called.** Where a test checks the request a fake received, the request *is* the behaviour
under test (e.g. the `before_id` cursor that prevents duplicates).

### Manual checks (run in Task 10 as each lands, all together in Task 12)

- **M-1 First load.** Signed in, launch: Timeline is the default page and shows the newest posts
  with avatar, name, @username, relative time (tooltip = absolute), body and thumbnails. Signed
  out: a clear "Sign in under Settings" hint, and no error.
- **M-2 Paging.** Scroll down steadily for at least 300 posts. Older posts load before you hit the
  bottom, with no duplicates (check the post just above and below each page boundary). Maximize a
  tall window with only one page loaded: older posts still load without scrolling.
- **M-3 Rendering.** Find posts with links, @-mentions, photos, blockquotes, lists, inline and
  block code, emoji, and a long post. Each renders legibly; links open in the default browser;
  @-mentions open micro.blog profiles in the browser (in-app profiles are M4).
- **M-4 New posts while scrolled down.** Scroll about 50 posts down; wait for a poll (or post from
  another client). The pill appears with the right count, **the post under your eyes does not
  move**, and clicking the pill (or F5) shows the new posts at the top and scrolls there. Pill
  count equals the number of posts inserted.
- **M-5 Unhandled HTML.** A post with a video/iframe/table (use the spike's sample set if the
  timeline has none) shows the text that could be shown plus "Part of this post can't be shown
  here", with Open in browser.
- **M-6 Broken image.** A post whose image 404s (spike sample) shows a placeholder tile, not a
  blank gap or a crash. Its accessible name still reads the alt text.
- **M-7 Failures.** Turn Wi-Fi off. Refresh: a warning InfoBar ("You appear to be offline…"), and
  the list is untouched. Scroll to the bottom: the footer shows "Couldn't load older posts" with
  Retry, and scrolling doesn't hammer the network. Wi-Fi on, Retry: loading resumes. Launch while
  offline: the error state with Retry; reconnect and the next poll loads the timeline by itself.
- **M-8 No avatar.** A user with no avatar shows initials in `PersonPicture`, not a crash. The
  spike's sample set includes one.
- **M-9 Fast scroll / recycling.** Fling-scroll up and down quickly. No avatar or photo ever
  appears on the wrong post, even briefly after settling.
- **M-10 Image viewer.** Click a thumbnail: the full-size image and its alt text ("No description"
  if empty). Left/Right move between a post's photos; Esc closes; "Open original" opens the
  browser.
- **M-11 Open in browser / Copy link.** Both work from the item's buttons. The copied link pastes
  correctly.
- **M-12 Keyboard + Narrator.** Tab into the list, arrow between posts, Tab to a post's links and
  buttons, Enter activates. Narrator announces "author, time ago: text" for a post and reads the
  pill and the footer states.
- **M-13 Themes.** Switch Windows light ↔ dark and turn on high contrast while the app is running.
  Text, links, quotes and code stay legible without restarting.
- **M-14 Scale.** Scroll back about 500 posts. Scrolling stays smooth and memory stays within
  Task 1's measured budget; `scripts/measure-memory.ps1` from Task 1 reports it.
- **M-15 Navigation.** Scroll down, open New post, come back: same position, same posts.

## Review Focus

How a timeline goes wrong, most likely first. Each one is pinned to the test or check that catches
it:

1. **Paging with `before_id`: duplicates, gaps, or an endless loop at the end.** The cursor is
   always the oldest *shown* id, so `before_id` can't gap. Duplicates from overlapping pages are
   dropped by id: `TimelineBufferTests.AppendOlder_OverlappingPage_AddsOnlyUnseenItems`. End of
   feed stops requests for good when a page is empty *or* adds nothing new (a server that ignores
   `before_id` and repeats a page would otherwise loop forever):
   `AppendOlder_EmptyPage_ReachesEnd`, `AppendOlder_AllDuplicates_ReachesEnd`,
   `TimelineViewModelTests.LoadOlder_AtEnd_CommandDisabled_NoFurtherRequests`. Also checked
   manually by M-2.
2. **The 2-minute poll arriving while scrolled down must not move the post under your eyes.** By
   construction, a poll only fills `Pending`; it never touches `Items`:
   `TimelinePollingTests.PollOnce_AddsToPending_NeverTouchesItems`. Also checked manually by M-4.
3. **"N new posts" and the list disagree.** The pill count is `Pending.Count`, repeated polls
   don't double-count, reveal inserts exactly the pending posts, and a possible gap reads "40+" and
   reveals by replacing the list: `TimelinePollingTests.PollOnce_Twice_CountsWithoutDuplicates_AndAsksFromTheNewestPending`,
   `ShowPending_InsertsExactlyThePendingPostsAtTop`, `PendingPillText_*`,
   `ShowPending_WithGap_ReplacesList_AndPagingContinuesFromTheNewOldest`. Also checked manually by
   M-4.
4. **HTML the renderer doesn't handle, and images that 404.** Unknown tags degrade to text;
   iframe/video/audio/embed/table set `HasUnsupportedContent`; malformed and 200-deep nesting don't
   throw; relative and non-http links never become `file:` links:
   `HtmlContentParserTests.*`. An image 404 returns null from the cache, never throws:
   `DiskImageCacheTests.NotFound_ReturnsNull_AndCachesNothing`. Also checked manually by M-3, M-5
   and M-6.
5. **A slow or failed refresh mid-scroll, and being offline.** A failed refresh or poll keeps
   `Items` and `Pending` and shows a warning; a failed load-older shows the footer error and
   disables the near-bottom trigger until Retry, so there's no request storm; a load-older answer
   that lands after the list was replaced is discarded; offline at launch recovers on the next
   poll: `TimelineViewModelTests.Refresh_Failure_KeepsEverything_AndWarns`,
   `LoadOlder_Failure_KeepsItems_ShowsFooterError_AndDisablesAutoTriggerUntilRetry`,
   `LoadOlder_ResultDiscarded_WhenListReplacedMeanwhile`,
   `TimelinePollingTests.PollOnce_Failure_KeepsEverything_AndBacksOff`,
   `PollOnce_BeforeFirstSuccessfulLoad_LoadsTheTimeline`. Also checked manually by M-7.
6. **A user with no avatar**, the shape of M1's crash: a missing, empty or whitespace `avatar`
   maps to `null` (`JsonFeedMapperTests.OddItems_AreNormalizedNotFatal`), and `CachedImage` treats
   null as "no image" and shows initials. Also checked manually by M-8.
7. **Recycled containers show the wrong image.** `CachedImage` clears the image immediately on
   every URL change and drops a download that completes after the container moved on. Also checked
   manually by M-9. This is view-only; no automated coverage.
8. **Rate limits.** The poll interval is clamped to at least 60 s, back-off doubles to a 30-min cap
   on any failure, and `Retry-After` is honoured: `PollScheduleTests.*`,
   `TimelineClientTests.TooManyRequests_CarriesRetryAfter`,
   `TimelinePollingTests.PollOnce_Failure_KeepsEverything_AndBacksOff`,
   `PollOnce_TooManyRequests_HonoursRetryAfter`.
9. **The token leaking to image hosts:**
   `DiskImageCacheTests.Download_SendsNoAuthorizationHeader`.
10. **One malformed item kills the whole page.** A missing id is skipped; an unparseable date,
    missing url, missing author, or numeric id is normalized:
    `JsonFeedMapperTests.OddItems_AreNormalizedNotFatal`. A non-JSON body becomes a
    `MicropubException`, not a crash: `TimelineClientTests.MalformedJson_ThrowsMicropubException`.

## Design decisions (context for the executor, not tasks)

- **New posts always wait behind the pill.** SPEC §4.1 says "New items appear behind a 'N new
  posts' pill; scroll position is preserved". A poll never inserts into the visible list, even
  when you're at the top, so the reading position can't move on its own. Clicking the pill,
  pressing F5/Ctrl+R, or the Refresh button reveals them and scrolls to the top. Scrolling to the
  top does **not** auto-reveal: that would shift content under a reader who's looking at the first
  post. The one exception is an empty list, where there's nothing to disturb. **For approval at
  Checkpoint 1.**
- **Gaps.** A `since_id` poll that returns a full page (40) may have skipped posts between it and
  what's shown. The pill then reads "40+ new posts", and revealing *replaces* the list with the
  fresh page. Paging older continues from there, so nothing is silently missing. This assumes
  `since_id` returns the *newest* posts newer than the id, as Mastodon-style APIs do. **Task 1
  confirms this against the real API.** If Micro.blog returns the posts *immediately after* the id
  instead, Task 4's `AddNewer` changes to "fetch again from the new newest until a short page"
  and the gap concept goes away. That is decided at Checkpoint 1, not guessed.
- **Page size 40** (`PageRequest.DefaultCount`). Task 1 records the server's maximum `count`.
- **Parsing in Core, drawing in App.** SPEC §5 puts `Rendering/HtmlToXamlConverter` in the App.
  This plan splits it into a WinUI-free `HtmlContentParser` → `RichContent` in `Transom.Core`
  (Linux-testable, which is where the edge cases live) and a thin `RichContentRenderer` in the App.
  Task 6 updates SPEC §5's tree (Rule 9).
- **Links use `Hyperlink.NavigateUri`**, so WinUI opens the default browser itself. That's
  keyboard- and Narrator-accessible with no app code that could fail silently. The parser only
  ever emits absolute http(s) URIs. M4's in-app @-mention routing replaces `NavigateUri` with a
  `Click` handler, which is the seam.
- **Timeline is the default page** (SPEC §4.1), with `NavigationCacheMode="Required"` so leaving
  it for New post and coming back keeps the list and scroll position (M-15).
- **Image cache:** `LocalCacheFolder/images`, 200 MB LRU (SPEC §8). Files are named by the SHA-256
  of the URL. Decoding happens at display size (`DecodePixelWidth`) to keep 200+ posts of photos
  within budget.
- **No actions M4 owns.** Reply, Conversation and Bookmark buttons are *not* shown, not even
  disabled. The item shows only Open in browser and Copy link.

## Out of scope, with the seams M4/M5 will use

- **M4:** conversations, replies, mentions, discover, bookmarks, in-app profiles. Seams:
  `FeedKind` (only `Timeline` now); `ITimelineProvider` gains `GetConversationAsync`/`ReplyAsync`/
  `SetBookmarkAsync` in M4, with every implementation and double updated together (Rule 10);
  `TimelineClient.GetFeedAsync(token, path, …)` already takes the feed path; `Hyperlink`
  `NavigateUri` becomes a routed `Click` for @-mentions.
- **Not in the M3 checklist, deferred unless you pull them in at Checkpoint 1:** "unread position
  remembered per feed across restarts" (SPEC §4.1) and "cached first page shown instantly" at cold
  start (SPEC §10). Both would persist `TimelineBuffer` state to `LocalCacheFolder`. The buffer is
  a plain class for that reason.
- Poll interval in Settings (SPEC §4.4): M3 uses the constant 2 min through `PollSchedule`, which
  already accepts a configurable interval.

## Execution and checkpoints

**Recommendation: a split.**

- **Task 1 inline.** It needs the running app, real data, measurements, and you at the keyboard
  for Narrator and the visual comparison.
- **Tasks 2–7 subagent-driven.** They are pure Core, plus one App service that runs without WinUI,
  fully specified, test-first. That's where a fresh implementer plus a fresh reviewer works well,
  and in M2 task review caught real bugs there (the `[]` field names, the dropped cancellation
  token).
- **Tasks 8–12 inline.** In M2 every bug that mattered in the view layer (the `DataContext`
  no-op, the remove-mid-upload crash, the overlapping dialogs) was invisible to diff review and
  surfaced only by running the app or by a deliberate audit. A reviewer who can't see the screen
  adds cost here, not safety. I'd run the app after each of these tasks instead.

**Checkpoints:**

1. **After Task 1: renderer decision.** I stop with the SPEC §12 write-up, the measurements, and a
   short list of things for you to try on the spike branch (Narrator, selection, the look next to
   micro.blog, light/dark). You approve the renderer, the pending-pill model, the `since_id`
   finding, and whether the two deferred items stay deferred. If WebView2 wins, I rewrite Tasks
   6, 7 and 10 and you see them before they run.
2. **After Task 10: first F5.** The timeline is on screen with paging, the pill and errors, before
   images, the viewer and polish. It's the cheapest point to catch "this feels wrong".
3. **After Task 12: final verification.** You run the manual checks; the PR stays a draft until

**Decision rule, fixed before measuring** (so the numbers can't be argued into a conclusion):
the converter wins if it (a) renders ≥ 95% of the captured posts with no visible content loss,
(b) reaches first item in ≤ 2 s cold (SPEC §10), (c) holds a median ≥ 55 fps on the scripted
scroll, (d) Narrator reads post text and links are reachable by Tab, and (e) follows a runtime
light/dark switch. Otherwise WebView2 wins if it meets (b), (c) and (d) at ≤ 400 MB total private
memory. If neither qualifies, I report and ask rather than pick.

**Protocol questions to answer from the captures (these go into SPEC §6.3):**
1. Exact item shape: `id` is a string or a number? `date_published` format; `author.avatar`
   present/empty/missing; `author._microblog.username`; the `_microblog` item fields.
2. How photos appear in `content_html` (`<img>` attributes, wrapped in `<a>`? `<figure>`?).
3. `since_id` semantics: take page 0, request `since_id=<id of item 10>&count=3`. Items 0–2
   (the newest) or items 7–9 (the ones right after)?
4. End of feed: on `mine.json`, follow `before_id` to the end. Is the last response an empty
   `items` array, or does it repeat?
5. Maximum `count`: request `count=100` and `count=200`. How many come back?
6. Response headers on a normal call: any rate-limit headers? Any `Retry-After` ever seen?

- [ ] **Step 5: Instrument**

Cold start is measured from process start, so it includes WebView2's runtime spin-up:

```csharp
// On first item rendered: converter = first ListView ContainerContentChanging with a realized
// item; WebView2 = a postMessage("rendered") sent from the page's DOMContentLoaded + first paint.
var sinceStart = DateTime.Now - System.Diagnostics.Process.GetCurrentProcess().StartTime;
File.AppendAllText(Path.Combine(ApplicationData.Current.LocalFolder.Path, "spike", "timings.csv"),
    $"{renderer},{DateTime.UtcNow:O},{sinceStart.TotalMilliseconds:F0}{Environment.NewLine}");
```

The renderer is picked from `LocalSettings["SpikeRenderer"]` at launch, so a cold launch goes
straight to it.

Frame rate during a scripted 10-second top-to-bottom scroll of 200 items: the converter counts
`CompositionTarget.Rendering` frames per second while stepping `ScrollViewer.ChangeView`. WebView2
renders in another process, so `CompositionTarget.Rendering` says nothing about its frames. It
counts `requestAnimationFrame` callbacks inside the page while `window.scrollBy` steps, and posts
the per-second counts back.

Memory counts the app **and every child process**. WebView2's browser and renderer processes are
children of the app, and measuring `Transom.App` alone would flatter WebView2:

```powershell
# scripts/measure-memory.ps1 — total private and working-set memory for the app and its
# process tree (WebView2 runs out of process).
param([string]$ProcessName = 'Transom.App')
$root = Get-Process -Name $ProcessName -ErrorAction Stop | Select-Object -First 1
$all = Get-CimInstance Win32_Process
function Get-Tree([int]$id) {
    $id
    $all | Where-Object ParentProcessId -eq $id | ForEach-Object { Get-Tree $_.ProcessId }
}
$procs = Get-Process -Id (Get-Tree $root.Id) -ErrorAction SilentlyContinue
[pscustomobject]@{
    Processes    = $procs.Count
    PrivateMB    = [math]::Round(($procs | Measure-Object PrivateMemorySize64 -Sum).Sum / 1MB, 1)
    WorkingSetMB = [math]::Round(($procs | Measure-Object WorkingSet64 -Sum).Sum / 1MB, 1)
}
```

```csharp
/// <summary>Which page of a feed to fetch (SPEC.md §6.3 pagination: <c>count</c>,
/// <c>before_id</c> for older, <c>since_id</c> for newer). At most one cursor is set, which is

{

        BeforeId = beforeId;
        SinceId = sinceId;

    /// <summary>Return posts newer than this id.</summary>
    public string? SinceId { get; }

    /// <summary>The page just older than <paramref name="beforeId"/>.</summary>
    public static PageRequest OlderThan(string beforeId, int count = DefaultCount) => new(count, beforeId, null);

    /// <summary>Posts newer than <paramref name="sinceId"/>.</summary>
```

```csharp
using System.Globalization;
using System.Text.Json;
using System.Text.Json.Serialization;

namespace Transom.Core.MicroBlog;

/// <summary>Reads a JSON string or number as a string. JSON Feed says <c>id</c> is a string, but
/// feeds in the wild send numbers. Any other token (object, array, bool) reads as null instead of
/// throwing, so one malformed item is skipped by <see cref="JsonFeedMapper"/> rather than failing
/// the whole page.</summary>
public sealed class StringOrNumberJsonConverter : JsonConverter<string?>
{
    /// <inheritdoc />
    public override string? Read(ref Utf8JsonReader reader, Type typeToConvert, JsonSerializerOptions options)
    {
        switch (reader.TokenType)
        {
            case JsonTokenType.String:
                return reader.GetString();
            case JsonTokenType.Number:
                return reader.TryGetInt64(out var whole)
                    ? whole.ToString(CultureInfo.InvariantCulture)
                    : reader.GetDouble().ToString(CultureInfo.InvariantCulture);
            default:
                reader.Skip();
                return null;
        }
    }

    /// <inheritdoc />
    public override void Write(Utf8JsonWriter writer, string? value, JsonSerializerOptions options)
    {
        if (value is null)
        {
            writer.WriteNullValue();
        }
        else
        {
            writer.WriteStringValue(value);
        }
    }
}
```

```csharp
using System.Globalization;

using Transom.Core.Models;

namespace Transom.Core.MicroBlog;

/// <summary>Maps the JSON Feed wire format to <see cref="TimelinePage"/>, normalizing what the
/// feed doesn't guarantee: an item without an id is skipped (it can't be paged or
/// de-duplicated); blank strings become null; an unparseable date becomes null.</summary>
public static class JsonFeedMapper
{
    /// <summary>Maps <paramref name="feed"/> (null means an empty page).</summary>
    public static TimelinePage ToPage(JsonFeed? feed)
    {
        var items = new List<TimelineItem>();
        foreach (var dto in feed?.Items ?? [])
        {
            if (dto is null || string.IsNullOrWhiteSpace(dto.Id))
            {
                continue;
            }

            items.Add(new TimelineItem(
                dto.Id,
                NullIfBlank(dto.Url),
                dto.ContentHtml ?? string.Empty,
                ParseDate(dto.DatePublished),
                new TimelineAuthor(
                    NullIfBlank(dto.Author?.Name),
                    NullIfBlank(dto.Author?.MicroBlog?.Username),
                    NullIfBlank(dto.Author?.Url),
                    NullIfBlank(dto.Author?.Avatar))));
        }

        return new TimelinePage(items);
    }

    private static string? NullIfBlank(string? value) => string.IsNullOrWhiteSpace(value) ? null : value.Trim();

    private static DateTimeOffset? ParseDate(string? value)
        => DateTimeOffset.TryParse(value, CultureInfo.InvariantCulture, DateTimeStyles.AssumeUniversal, out var parsed) ? parsed : null;
}
```

```csharp
/// <summary>Sending shared by every Micro.blog client.</summary>
internal static class MicroBlogHttp
{
    /// <summary>
    /// Sends the request and translates connectivity failures (no route to host, DNS failure,
    /// timeout) into <see cref="MicropubException"/> with a null <c>StatusCode</c>, so callers only
    /// ever handle one exception type for Micro.blog failures. A <see cref="TaskCanceledException"/>
    /// caused by the caller's own <paramref name="cancellationToken"/> is left alone: that is a
    /// deliberate cancellation, not a failure to report.

    public static async Task<HttpResponseMessage> SendAsync(HttpClient httpClient, HttpRequestMessage request, CancellationToken cancellationToken)
    {
        try
        {
            return await httpClient.SendAsync(request, cancellationToken).ConfigureAwait(false);
        }
        catch (HttpRequestException ex)
        {
            throw new MicropubException(null, ex.Message, ex);
        }
        catch (TaskCanceledException ex) when (!cancellationToken.IsCancellationRequested)
        {
            throw new MicropubException(null, "The request timed out.", ex);
        }
    }
}
```

```csharp
        request.Headers.Authorization = new AuthenticationHeaderValue("Bearer", token);

        }
        catch (JsonException ex)
        {
            throw new MicropubException(response.StatusCode, "Micro.blog sent a timeline Transom couldn't read.", ex);
        }

        return JsonFeedMapper.ToPage(feed);
    }
```

```csharp
using Transom.Core.Models;

namespace Transom.Core.Timeline;

/// <summary>What <see cref="TimelineBuffer.RevealPending"/> did: the posts it revealed (newest
/// first), and whether they replaced the whole list rather than going on top of it.</summary>
public sealed record RevealResult(IReadOnlyList<TimelineItem> Revealed, bool ReplacedAll);

/// <summary>
/// The timeline's paging state: the posts shown (<see cref="Items"/>) and the new posts that have
/// arrived but aren't shown yet (<see cref="Pending"/>, behind the "N new posts" pill, SPEC.md
/// §4.1). Every post id appears at most once across both. New posts only ever enter
/// <see cref="Pending"/>, so a poll can't move what the user is reading.
/// </summary>
public sealed class TimelineBuffer
{
    private readonly List<TimelineItem> _items = [];
    private readonly List<TimelineItem> _pending = [];
    private readonly HashSet<string> _ids = new(StringComparer.Ordinal);

    /// <summary>Posts shown, newest first.</summary>
    public IReadOnlyList<TimelineItem> Items => _items;

    /// <summary>Posts newer than <see cref="Items"/> that haven't been revealed, newest first.</summary>
    public IReadOnlyList<TimelineItem> Pending => _pending;

    /// <summary>True once a first page has loaded (even an empty one).</summary>
    public bool HasLoaded { get; private set; }

    /// <summary>True when there is nothing older to load; stops infinite scroll for good.</summary>
    public bool ReachedEnd { get; private set; }

    /// <summary>True when a poll came back full, so posts between <see cref="Pending"/> and
    /// <see cref="Items"/> may be missing; revealing then replaces the list.</summary>
    public bool PendingHasGap { get; private set; }

    /// <summary>Changes whenever <see cref="Items"/> is replaced wholesale. A caller that awaited
    /// a page compares it before and after, and drops the page if the list changed meanwhile.</summary>
    public int Generation { get; private set; }

    /// <summary>Cursor for <c>before_id</c>: the oldest shown post.</summary>
    public string? OldestId => _items.Count > 0 ? _items[^1].Id : null;

    /// <summary>Cursor for <c>since_id</c>: the newest post seen, pending included.</summary>
    public string? NewestId => _pending.Count > 0 ? _pending[0].Id : _items.Count > 0 ? _items[0].Id : null;

    /// <summary>Replaces everything with a first page.</summary>
    public void Reset(TimelinePage page)
    {
        ClearState();
        foreach (var item in page.Items)
        {
            if (_ids.Add(item.Id))
            {
                _items.Add(item);
            }
        }

        HasLoaded = true;
        ReachedEnd = _items.Count == 0;
    }

    /// <summary>Appends an older page below <see cref="Items"/>, skipping posts already present.
    /// A page that adds nothing (empty, or all duplicates) marks <see cref="ReachedEnd"/>.</summary>
    /// <returns>The posts appended, in order.</returns>
    public IReadOnlyList<TimelineItem> AppendOlder(TimelinePage page)
    {
        var added = new List<TimelineItem>();
        foreach (var item in page.Items)
        {
            if (_ids.Add(item.Id))
            {
                _items.Add(item);
                added.Add(item);
            }
        }

        if (added.Count == 0)
        {
            ReachedEnd = true;
        }

        return added;
    }

    /// <summary>Adds a newer page (from <c>since_id</c>) to <see cref="Pending"/>, skipping posts
    /// already present. A page of <paramref name="requestedCount"/> or more may not reach back to
    /// what's shown, so it flags <see cref="PendingHasGap"/>.</summary>
    /// <returns>How many posts were new.</returns>
    public int AddNewer(TimelinePage page, int requestedCount)
    {
        var fresh = new List<TimelineItem>();
        foreach (var item in page.Items)
        {
            if (_ids.Add(item.Id))
            {
                fresh.Add(item);
            }
        }

        _pending.InsertRange(0, fresh);
        if (page.Items.Count >= requestedCount)
        {
            PendingHasGap = true;
        }

        return fresh.Count;
    }

    /// <summary>Moves <see cref="Pending"/> into <see cref="Items"/>: on top, or replacing the
    /// list when <see cref="PendingHasGap"/> is set.</summary>
    public RevealResult RevealPending()
    {
        if (_pending.Count == 0)
        {
            return new RevealResult([], ReplacedAll: false);
        }

        var revealed = _pending.ToList();
        var replaceAll = PendingHasGap;
        if (replaceAll)
        {
            foreach (var old in _items)
            {
                _ids.Remove(old.Id);
            }

            _items.Clear();
            _items.AddRange(revealed);
            ReachedEnd = false;
            Generation++;
        }
        else
        {
            _items.InsertRange(0, revealed);
        }

        _pending.Clear();
        PendingHasGap = false;
        return new RevealResult(revealed, replaceAll);
    }

    /// <summary>Forgets everything, e.g. after sign-out.</summary>
    public void Clear()
    {
        ClearState();
        HasLoaded = false;
        ReachedEnd = false;
    }

    private void ClearState()
    {
        _items.Clear();
        _pending.Clear();
        _ids.Clear();
        PendingHasGap = false;
        Generation++;
    }
}
```

```csharp
namespace Transom.Core.Timeline;

/// <summary>
/// When to poll next (SPEC.md §6.4): every <see cref="Interval"/> (default 2 min, never under 60 s);
/// after consecutive failures, double it each time up to <see cref="MaximumBackoff"/>, and never
/// sooner than the server's <c>Retry-After</c>. Any failure backs off, not just 429/5xx. Retrying
/// every 2 minutes against an offline network or a revoked token helps nobody.
/// </summary>
public sealed class PollSchedule
{
    private int _consecutiveFailures;
    private TimeSpan? _retryAfter;

    /// <summary>Creates a schedule; <paramref name="interval"/> is clamped to
    /// <see cref="MinimumInterval"/>.</summary>
    public PollSchedule(TimeSpan? interval = null)
    {
        var requested = interval ?? DefaultInterval;
        Interval = requested < MinimumInterval ? MinimumInterval : requested;
    }

    /// <summary>The floor SPEC.md §6.4 sets: 60 seconds.</summary>
    public static TimeSpan MinimumInterval { get; } = TimeSpan.FromSeconds(60);

    /// <summary>The default poll interval: 2 minutes (SPEC.md §4.1).</summary>
    public static TimeSpan DefaultInterval { get; } = TimeSpan.FromMinutes(2);

    /// <summary>The longest exponential back-off: 30 minutes.</summary>
    public static TimeSpan MaximumBackoff { get; } = TimeSpan.FromMinutes(30);

    /// <summary>The healthy poll interval.</summary>
    public TimeSpan Interval { get; }

    /// <summary>How long to wait before the next poll.</summary>
    public TimeSpan NextDelay
    {
        get
        {
            if (_consecutiveFailures == 0)
            {
                return Interval;
            }

            var factor = Math.Pow(2, Math.Min(_consecutiveFailures, 16));
            var backoff = TimeSpan.FromTicks((long)Math.Min(Interval.Ticks * factor, MaximumBackoff.Ticks));
            if (backoff < Interval)
            {
                backoff = Interval;
            }

            return _retryAfter is { } retryAfter && retryAfter > backoff ? retryAfter : backoff;
        }
    }

    /// <summary>Records a successful fetch; the next delay is back to <see cref="Interval"/>.</summary>
    public void RecordSuccess()
    {
        _consecutiveFailures = 0;
        _retryAfter = null;
    }

    /// <summary>Records a failed fetch and the server's <c>Retry-After</c>, if it sent one.</summary>
    public void RecordFailure(TimeSpan? retryAfter)
    {
        _consecutiveFailures++;
        _retryAfter = retryAfter;
    }
}
```

```csharp
using System.Globalization;

namespace Transom.Core.Timeline;

/// <summary>Post timestamps for the timeline (SPEC.md §4.1: relative time, tooltip = absolute).
/// Dates are shown in the viewer's offset, taken from <c>now</c>. A missing date gives an empty
/// string; a future date (clock skew) counts as "now".</summary>
public static class RelativeTime
{
    /// <summary>Compact form for the item header: "now", "4m", "3h", "2d", "Sep 12", "Sep 12, 2025".</summary>
    public static string Short(DateTimeOffset? published, DateTimeOffset now, CultureInfo culture)
    {
        if (published is not { } value)
        {
            return string.Empty;
        }

        var age = now - value;
        if (age < TimeSpan.FromMinutes(1))
        {
            return "now";
        }
        if (age < TimeSpan.FromHours(1))
        {
            return $"{(int)age.TotalMinutes}m";
        }
        if (age < TimeSpan.FromDays(1))
        {
            return $"{(int)age.TotalHours}h";
        }
        if (age < TimeSpan.FromDays(7))
        {
            return $"{(int)age.TotalDays}d";
        }

        var local = value.ToOffset(now.Offset);
        return local.ToString(local.Year == now.Year ? "MMM d" : "MMM d, yyyy", culture);
    }

    /// <summary>Spoken form for accessible names: "just now", "4 minutes ago", "September 12".</summary>
    public static string Spoken(DateTimeOffset? published, DateTimeOffset now, CultureInfo culture)
    {
        if (published is not { } value)
        {
            return string.Empty;
        }

        var age = now - value;
        if (age < TimeSpan.FromMinutes(1))
        {
            return "just now";
        }
        if (age < TimeSpan.FromHours(1))
        {
            return Ago((int)age.TotalMinutes, "minute");
        }
        if (age < TimeSpan.FromDays(1))
        {
            return Ago((int)age.TotalHours, "hour");
        }
        if (age < TimeSpan.FromDays(7))
        {
            return Ago((int)age.TotalDays, "day");
        }

        var local = value.ToOffset(now.Offset);
        return local.ToString(local.Year == now.Year ? "MMMM d" : "MMMM d, yyyy", culture);
    }

    /// <summary>Full date and time for the tooltip, in the culture's long pattern.</summary>
    public static string Absolute(DateTimeOffset? published, DateTimeOffset now, CultureInfo culture)
        => published is { } value ? value.ToOffset(now.Offset).ToString("f", culture) : string.Empty;

    private static string Ago(int count, string unit) => count == 1 ? $"1 {unit} ago" : $"{count} {unit}s ago";
}
```

```csharp
using System.Text;

namespace Transom.Core.Rendering;

/// <summary>Inline text styles; combinable.</summary>
[Flags]
public enum RichStyle
{
    /// <summary>Plain.</summary>
    None = 0,
    /// <summary>strong/b.</summary>
    Bold = 1,
    /// <summary>em/i.</summary>
    Italic = 2,
    /// <summary>Inline code.</summary>
    Code = 4,
}

/// <summary>A block of post content.</summary>
public abstract record RichBlock;

/// <summary>A paragraph of inlines.</summary>
public sealed record RichParagraph(IReadOnlyList<RichInline> Inlines) : RichBlock;

/// <summary>A blockquote.</summary>
public sealed record RichQuote(IReadOnlyList<RichBlock> Blocks) : RichBlock;

/// <summary>A list; each item is its own sequence of blocks.</summary>
public sealed record RichList(bool Ordered, IReadOnlyList<IReadOnlyList<RichBlock>> Items) : RichBlock;

/// <summary>Preformatted code, whitespace preserved.</summary>
public sealed record RichCodeBlock(string Text) : RichBlock;

/// <summary>An inline element.</summary>
public abstract record RichInline;

/// <summary>A run of text in one style.</summary>
public sealed record RichText(string Text, RichStyle Style) : RichInline;

/// <summary>A link. <see cref="Href"/> is always an absolute http(s) URI, and
/// <see cref="Inlines"/> never contains another link.</summary>
public sealed record RichLink(string Href, IReadOnlyList<RichInline> Inlines) : RichInline;

/// <summary>A line break.</summary>
public sealed record RichLineBreak : RichInline;

/// <summary>An image taken out of the text flow, shown as a thumbnail below it.</summary>
public sealed record RichImage(string Url, string? AltText);

/// <summary>A post body parsed for native rendering (SPEC.md §6.3).
/// <see cref="HasUnsupportedContent"/> means something couldn't be shown (video, iframe, table,
/// extreme nesting), so the UI offers Open in browser.</summary>
public sealed record RichContent(IReadOnlyList<RichBlock> Blocks, IReadOnlyList<RichImage> Images, bool HasUnsupportedContent)
{
    /// <summary>No content.</summary>
    public static RichContent Empty { get; } = new([], [], false);

    /// <summary>The text for accessible names and previews, whitespace-collapsed, truncated with "…"
    /// past <paramref name="maxLength"/>.</summary>
    public string ToPlainText(int maxLength = int.MaxValue)
    {
        var builder = new StringBuilder();
        AppendBlocks(builder, Blocks);
        var text = builder.ToString().Trim();
        return text.Length <= maxLength ? text : string.Concat(text.AsSpan(0, maxLength - 1).TrimEnd(), "…");
    }

    private static void AppendBlocks(StringBuilder builder, IEnumerable<RichBlock> blocks)
    {
        foreach (var block in blocks)
        {
            switch (block)
            {
                case RichParagraph paragraph:
                    AppendInlines(builder, paragraph.Inlines);
                    break;
                case RichQuote quote:
                    AppendBlocks(builder, quote.Blocks);
                    break;
                case RichList list:
                    foreach (var item in list.Items)
                    {
                        AppendBlocks(builder, item);
                    }
                    break;
                case RichCodeBlock code:
                    builder.Append(code.Text);
                    break;
            }

            if (builder.Length > 0 && builder[^1] != ' ')
            {
                builder.Append(' ');
            }
        }
    }

    private static void AppendInlines(StringBuilder builder, IEnumerable<RichInline> inlines)
    {
        foreach (var inline in inlines)
        {
            switch (inline)
            {
                case RichText text:
                    builder.Append(text.Text);
                    break;
                case RichLink link:
                    AppendInlines(builder, link.Inlines);
                    break;
                case RichLineBreak:
                    builder.Append(' ');
                    break;
            }
        }
    }
}
```

```csharp
using System.Text.RegularExpressions;

using HtmlAgilityPack;

namespace Transom.Core.Rendering;

/// <summary>Parses a post's <c>content_html</c> into <see cref="RichContent"/>. See the task notes
/// in the M3 plan and SPEC.md §6.3 for the tag rules. Never throws on bad HTML.</summary>
public static partial class HtmlContentParser
{
    private const int MaxDepth = 32;

    private static readonly HashSet<string> Dropped = new(StringComparer.OrdinalIgnoreCase)
        { "script", "style", "template", "noscript", "head", "title", "meta", "link" };

    private static readonly HashSet<string> Unsupported = new(StringComparer.OrdinalIgnoreCase)
        { "iframe", "video", "audio", "object", "embed", "canvas", "svg", "math", "form", "input", "button", "select", "textarea" };

    private static readonly HashSet<string> Blocks = new(StringComparer.OrdinalIgnoreCase)
    {
        "p", "div", "blockquote", "ul", "ol", "li", "pre", "h1", "h2", "h3", "h4", "h5", "h6", "hr",
        "table", "thead", "tbody", "tfoot", "tr", "figure", "figcaption", "section", "article",
        "header", "footer", "aside", "details", "summary", "dl", "dt", "dd", "address", "main", "nav",
    };

    /// <summary>Parses <paramref name="html"/>; relative links and images resolve against
    /// <paramref name="baseUri"/> (the post's URL) or are dropped if there is none.</summary>
    public static RichContent Parse(string? html, Uri? baseUri = null)
    {
        if (string.IsNullOrWhiteSpace(html))
        {
            return RichContent.Empty;
        }

        var document = new HtmlDocument();
        document.LoadHtml(html);
        var context = new Context(baseUri);
        var blocks = context.ParseBlocks(document.DocumentNode.ChildNodes, depth: 0);
        return new RichContent(blocks, context.Images, context.HasUnsupportedContent);
    }

    [GeneratedRegex(@"\s+")]
    private static partial Regex Whitespace();

    private static string Text(HtmlNode node) => HtmlEntity.DeEntitize(node.InnerText) ?? string.Empty;

    private static string Collapse(string text) => Whitespace().Replace(text, " ");

    private sealed class Context(Uri? baseUri)
    {
        private readonly HashSet<string> _imageUrls = new(StringComparer.Ordinal);

        public List<RichImage> Images { get; } = [];

        public bool HasUnsupportedContent { get; private set; }

        public List<RichBlock> ParseBlocks(IEnumerable<HtmlNode> nodes, int depth)
        {
            var blocks = new List<RichBlock>();
            var inlines = new List<RichInline>();
            foreach (var node in nodes)
            {
                if (node.NodeType == HtmlNodeType.Element && Blocks.Contains(node.Name))
                {
                    Flush(blocks, inlines);
                    blocks.AddRange(ParseBlockElement(node, depth + 1));
                }
                else
                {
                    inlines.AddRange(ParseInline(node, RichStyle.None, depth + 1, insideLink: false));
                }
            }

            Flush(blocks, inlines);
            return blocks;
        }

        private IEnumerable<RichBlock> ParseBlockElement(HtmlNode node, int depth)
        {
            if (depth > MaxDepth)
            {
                return Flattened(node);
            }

            switch (node.Name)
            {
                case "blockquote":
                    var quoted = ParseBlocks(node.ChildNodes, depth);
                    return quoted.Count == 0 ? [] : [new RichQuote(quoted)];
                case "ul":
                case "ol":
                    var items = node.ChildNodes
                        .Where(child => child.Name == "li")
                        .Select(li => (IReadOnlyList<RichBlock>)ParseBlocks(li.ChildNodes, depth + 1))
                        .ToList();
                    return items.Count == 0 ? [] : [new RichList(node.Name == "ol", items)];
                case "pre":
                    var code = Text(node).Replace("\r\n", "\n").TrimEnd('\n', ' ');
                    return code.Length == 0 ? [] : [new RichCodeBlock(code)];
                case "h1" or "h2" or "h3" or "h4" or "h5" or "h6":
                    var heading = Trim(node.ChildNodes.SelectMany(child => ParseInline(child, RichStyle.Bold, depth + 1, insideLink: false)).ToList());
                    return heading.Count == 0 ? [] : [new RichParagraph(heading)];
                case "hr":
                    return [];
                case "table":
                    HasUnsupportedContent = true;
                    return ParseBlocks(node.ChildNodes, depth);
                default:
                    return ParseBlocks(node.ChildNodes, depth);
            }
        }

        private IEnumerable<RichInline> ParseInline(HtmlNode node, RichStyle style, int depth, bool insideLink)
        {
            if (node.NodeType == HtmlNodeType.Text)
            {
                var text = Collapse(Text(node));
                return text.Length == 0 ? [] : [new RichText(text, style)];
            }
            if (node.NodeType != HtmlNodeType.Element)
            {
                return [];
            }
            if (Dropped.Contains(node.Name))
            {
                return [];
            }
            if (Unsupported.Contains(node.Name))
            {
                HasUnsupportedContent = true;
                return [];
            }
            if (depth > MaxDepth)
            {
                HasUnsupportedContent = true;
                var flat = Collapse(Text(node));
                return flat.Length == 0 ? [] : [new RichText(flat, style)];
            }

            switch (node.Name)
            {
                case "br":
                    return [new RichLineBreak()];
                case "img":
                    AddImage(node);
                    return [];
                case "strong" or "b":
                    return Children(node, style | RichStyle.Bold, depth, insideLink);
                case "em" or "i":
                    return Children(node, style | RichStyle.Italic, depth, insideLink);
                case "code":
                    return Children(node, style | RichStyle.Code, depth, insideLink);
                case "td" or "th":
                    return [.. Children(node, style, depth, insideLink), new RichText(" ", style)];
                case "a":
                    var href = insideLink ? null : Resolve(HtmlEntity.DeEntitize(node.GetAttributeValue("href", string.Empty)));
                    var children = Children(node, style, depth, insideLink: insideLink || href is not null);
                    return href is null || children.Count == 0 ? children : [new RichLink(href.AbsoluteUri, children)];
                default:
                    return Children(node, style, depth, insideLink);
            }
        }

        private List<RichInline> Children(HtmlNode node, RichStyle style, int depth, bool insideLink)
            => node.ChildNodes.SelectMany(child => ParseInline(child, style, depth + 1, insideLink)).ToList();

        private IEnumerable<RichBlock> Flattened(HtmlNode node)
        {
            HasUnsupportedContent = true;
            var text = Collapse(Text(node)).Trim();
            return text.Length == 0 ? [] : [new RichParagraph([new RichText(text, RichStyle.None)])];
        }

        private void AddImage(HtmlNode node)
        {
            if (Resolve(HtmlEntity.DeEntitize(node.GetAttributeValue("src", string.Empty))) is { } uri && _imageUrls.Add(uri.AbsoluteUri))
            {
                var alt = HtmlEntity.DeEntitize(node.GetAttributeValue("alt", string.Empty))?.Trim();
                Images.Add(new RichImage(uri.AbsoluteUri, string.IsNullOrEmpty(alt) ? null : alt));
            }
        }

        // Only absolute http(s) survives. On Linux, Uri.TryCreate("/x", Absolute) yields file:///x,
        // hence the scheme check before falling back to resolving against the post.
        private Uri? Resolve(string? value)
        {
            if (string.IsNullOrWhiteSpace(value))
            {
                return null;
            }

            value = value.Trim();
            if (Uri.TryCreate(value, UriKind.Absolute, out var absolute) && IsHttp(absolute))
            {
                return absolute;
            }

            return baseUri is not null && Uri.TryCreate(baseUri, value, out var relative) && IsHttp(relative) ? relative : null;
        }

        private static bool IsHttp(Uri uri) => uri.Scheme == Uri.UriSchemeHttp || uri.Scheme == Uri.UriSchemeHttps;

        private static void Flush(List<RichBlock> blocks, List<RichInline> inlines)
        {
            var trimmed = Trim(inlines);
            if (trimmed.Count > 0)
            {
                blocks.Add(new RichParagraph(trimmed));
            }

            inlines.Clear();
        }

        // Trims whitespace at the paragraph's edges and after each line break, and drops runs that
        // end up empty.
        private static List<RichInline> Trim(List<RichInline> inlines)
        {
            var result = new List<RichInline>();
            var atLineStart = true;
            foreach (var inline in inlines)
            {
                if (inline is RichText text)
                {
                    var value = atLineStart ? text.Text.TrimStart() : text.Text;
                    if (value.Length == 0)
                    {
                        continue;
                    }

                    result.Add(text with { Text = value });
                    atLineStart = false;
                }
                else
                {
                    if (inline is RichLineBreak && result.Count > 0 && result[^1] is RichText before)
                    {
                        result[^1] = before with { Text = before.Text.TrimEnd() };
                    }

                    result.Add(inline);
                    atLineStart = inline is RichLineBreak;
                }
            }

            while (result.Count > 0 && result[^1] is RichLineBreak)
            {
                result.RemoveAt(result.Count - 1);
            }
            if (result.Count > 0 && result[^1] is RichText last)
            {
                var value = last.Text.TrimEnd();
                if (value.Length == 0)
                {
                    result.RemoveAt(result.Count - 1);
                }
                else
                {
                    result[^1] = last with { Text = value };
                }
            }

            return result;
        }
    }
}
```

```csharp
namespace Transom.Core.Caching;

/// <summary>Size and last-use bookkeeping for a size-capped cache (SPEC.md §8: 200 MB, LRU). Only
/// the bookkeeping; the caller owns the files and deletes what <see cref="EvictToFit"/> returns.
/// Not thread-safe; callers serialize access.</summary>
public sealed class LruCacheIndex
{
    private readonly Dictionary<string, (long Size, DateTimeOffset LastUsed)> _entries = new(StringComparer.Ordinal);

    /// <summary>Total size of all entries.</summary>
    public long TotalBytes { get; private set; }

    /// <summary>Number of entries.</summary>
    public int Count => _entries.Count;

    /// <summary>Adds or updates an entry and marks it used at <paramref name="accessedAt"/>.</summary>
    public void Touch(string key, long sizeBytes, DateTimeOffset accessedAt)
    {
        if (_entries.TryGetValue(key, out var existing))
        {
            TotalBytes -= existing.Size;
        }

        _entries[key] = (sizeBytes, accessedAt);
        TotalBytes += sizeBytes;
    }

    /// <summary>Removes an entry if present.</summary>
    public void Remove(string key)
    {
        if (_entries.Remove(key, out var existing))
        {
            TotalBytes -= existing.Size;
        }
    }

    /// <summary>Removes least-recently-used entries until <see cref="TotalBytes"/> ≤
    /// <paramref name="capacityBytes"/>.</summary>
    /// <returns>The removed keys, oldest first.</returns>
    public IReadOnlyList<string> EvictToFit(long capacityBytes)
    {
        var evicted = new List<string>();
        foreach (var (key, _) in _entries.OrderBy(e => e.Value.LastUsed).ThenBy(e => e.Key, StringComparer.Ordinal).ToList())
        {
            if (TotalBytes <= capacityBytes)
            {
                break;
            }

            Remove(key);
            evicted.Add(key);
        }

        return evicted;
    }
}
```

```csharp
/// <summary>
/// <see cref="IImageCache"/> over a folder (SPEC.md §8: <c>LocalCacheFolder</c>, 200 MB, LRU).
/// Files are named by the SHA-256 of the URL. Downloads go through the <see cref="HttpClientName"/>
/// client, which carries no Authorization header, so the Micro.blog token never reaches an image
/// host. Failures are logged as warnings and read as "no image"; the UI shows a placeholder.
/// </summary>
public sealed class DiskImageCache : IImageCache
{
    /// <summary>Named <see cref="HttpClient"/> for image downloads.</summary>
    public const string HttpClientName = "images";

    /// <summary>SPEC.md §8's cap.</summary>
    public const long DefaultCapacityBytes = 200L * 1024 * 1024;

    private const long MaxFileBytes = 20L * 1024 * 1024;

    private readonly IHttpClientFactory _httpClientFactory;
    private readonly string _folder;
    private readonly ILogger<DiskImageCache> _logger;
    private readonly TimeProvider _time;
    private readonly long _capacityBytes;
    private readonly LruCacheIndex _index = new();
    private readonly SemaphoreSlim _indexLock = new(1, 1);
    private readonly ConcurrentDictionary<string, Task<string?>> _inFlight = new(StringComparer.Ordinal);
    private bool _indexLoaded;

    public DiskImageCache(IHttpClientFactory httpClientFactory, string folder, ILogger<DiskImageCache> logger, TimeProvider time, long capacityBytes = DefaultCapacityBytes)
    {
        _httpClientFactory = httpClientFactory;
        _folder = folder;
        _logger = logger;
        _time = time;
        _capacityBytes = capacityBytes;
    }

    public Task<string?> GetLocalUriAsync(string? url, CancellationToken cancellationToken)
    {
        if (string.IsNullOrWhiteSpace(url)
            || !Uri.TryCreate(url.Trim(), UriKind.Absolute, out var uri)
            || (uri.Scheme != Uri.UriSchemeHttp && uri.Scheme != Uri.UriSchemeHttps))
        {
            return Task.FromResult<string?>(null);
        }

        var key = Convert.ToHexStringLower(SHA256.HashData(Encoding.UTF8.GetBytes(uri.AbsoluteUri)));

        // One download per URL, shared by every caller. It deliberately runs on CancellationToken.None
        // (the one exception to CLAUDE.md Rule 4 in this milestone): one recycled container
        // cancelling mustn't cancel the download another container is waiting for. Each caller
        // waits with its own token instead.
        var shared = _inFlight.GetOrAdd(key, k => FetchAndForgetAsync(uri, k));
        return shared.WaitAsync(cancellationToken);
    }

    private async Task<string?> FetchAndForgetAsync(Uri uri, string key)
    {
        try
        {
            return await FetchAsync(uri, key).ConfigureAwait(false);
        }
        finally
        {
            _inFlight.TryRemove(key, out _);
        }
    }

    private async Task<string?> FetchAsync(Uri uri, string key)
    {
        await Task.Yield();
        try
        {
            await _indexLock.WaitAsync(CancellationToken.None).ConfigureAwait(false);
            try
            {
                LoadIndexOnce();
                if (FindCached(key) is { } cached)
                {
                    File.SetLastWriteTimeUtc(cached, _time.GetUtcNow().UtcDateTime);
                    _index.Touch(key, new FileInfo(cached).Length, _time.GetUtcNow());
                    return new Uri(cached).AbsoluteUri;
                }
            }
            finally
            {
                _indexLock.Release();
            }

            using var client = _httpClientFactory.CreateClient(HttpClientName);
            using var response = await client.GetAsync(uri, HttpCompletionOption.ResponseHeadersRead, CancellationToken.None).ConfigureAwait(false);
            if (!response.IsSuccessStatusCode)
            {
                _logger.LogWarning("Image {Url} returned {Status}", uri, (int)response.StatusCode);
                return null;
            }

            var extension = ExtensionFor(response.Content.Headers.ContentType?.MediaType);
            if (extension is null || response.Content.Headers.ContentLength > MaxFileBytes)
            {
                _logger.LogWarning("Image {Url} is not a supported image or is too large", uri);
                return null;
            }

            Directory.CreateDirectory(_folder);
            var path = Path.Combine(_folder, key + extension);
            var partial = path + ".part";
            await using (var source = await response.Content.ReadAsStreamAsync(CancellationToken.None).ConfigureAwait(false))
            await using (var target = File.Create(partial))
            {
                var buffer = new byte[81920];
                long total = 0;
                int read;
                while ((read = await source.ReadAsync(buffer, CancellationToken.None).ConfigureAwait(false)) > 0)
                {
                    total += read;
                    if (total > MaxFileBytes)
                    {
                        throw new InvalidDataException("Image exceeds the size limit.");
                    }

                    await target.WriteAsync(buffer.AsMemory(0, read), CancellationToken.None).ConfigureAwait(false);
                }
            }

            File.Move(partial, path, overwrite: true);
            await RecordAndEvictAsync(key, path).ConfigureAwait(false);
            return new Uri(path).AbsoluteUri;
        }
        catch (Exception ex)
        {
            _logger.LogWarning(ex, "Couldn't cache image {Url}", uri);
            return null;
        }
    }

    private async Task RecordAndEvictAsync(string key, string path)
    {
        await _indexLock.WaitAsync(CancellationToken.None).ConfigureAwait(false);
        try
        {
            _index.Touch(key, new FileInfo(path).Length, _time.GetUtcNow());
            foreach (var evicted in _index.EvictToFit(_capacityBytes))
            {
                if (FindCached(evicted) is { } file)
                {
                    File.Delete(file);
                }
            }
        }
        finally
        {
            _indexLock.Release();
        }
    }

    // Caller holds _indexLock.
    private void LoadIndexOnce()
    {
        if (_indexLoaded)
        {
            return;
        }

        _indexLoaded = true;
        if (!Directory.Exists(_folder))
        {
            return;
        }

        foreach (var file in new DirectoryInfo(_folder).EnumerateFiles())
        {
            if (file.Extension == ".part")
            {
                file.Delete();
                continue;
            }

            _index.Touch(Path.GetFileNameWithoutExtension(file.Name), file.Length, file.LastWriteTimeUtc);
        }
    }

    private string? FindCached(string key)
        => Directory.Exists(_folder) ? Directory.EnumerateFiles(_folder, key + ".*").FirstOrDefault(f => !f.EndsWith(".part", StringComparison.Ordinal)) : null;

    private static string? ExtensionFor(string? mediaType) => mediaType?.ToLowerInvariant() switch
    {
        "image/jpeg" or "image/jpg" => ".jpg",
        "image/png" => ".png",
        "image/gif" => ".gif",
        "image/webp" => ".webp",
        _ => null,
    };
}
```

```csharp
using System.Collections.ObjectModel;

using CommunityToolkit.Mvvm.ComponentModel;
using CommunityToolkit.Mvvm.Input;

using Microsoft.Extensions.Logging;

using Transom.App.Services;
using Transom.Core.Credentials;
using Transom.Core.MicroBlog;
using Transom.Core.Models;
using Transom.Core.Providers;
using Transom.Core.Timeline;

namespace Transom.App.ViewModels;

/// <summary>
/// The timeline (SPEC.md §4.1, story U4). Paging and new-post state live in
/// <see cref="TimelineBuffer"/>; this class mirrors it into <see cref="Items"/> and owns the error
/// surfaces. New posts never enter <see cref="Items"/> without a user action (Refresh, or the pill
/// in Task 9), so the reading position can't move on its own. No WinUI types (CLAUDE.md Rule 5).
/// </summary>
public sealed partial class TimelineViewModel : ObservableObject
{
    private readonly ITimelineProvider _provider;
    private readonly ICredentialStore _credentials;
    private readonly ILinkOpener _links;
    private readonly IClipboardService _clipboard;
    private readonly TimeProvider _time;
    private readonly ILogger<TimelineViewModel> _logger;
    private readonly TimelineBuffer _buffer = new();
    private readonly PollSchedule _schedule = new();

    [ObservableProperty]
    [NotifyPropertyChangedFor(nameof(ShowSignInHint), nameof(ShowEmptyState))]
    private bool _isSignedIn;

    [ObservableProperty]
    [NotifyPropertyChangedFor(nameof(ShowEmptyState))]
    [NotifyCanExecuteChangedFor(nameof(LoadOlderCommand))]
    private bool _isLoading;

    [ObservableProperty]
    [NotifyCanExecuteChangedFor(nameof(LoadOlderCommand))]
    private bool _isLoadingOlder;

    [ObservableProperty]
    private bool _isRefreshing;

    [ObservableProperty]
    [NotifyPropertyChangedFor(nameof(ShowEmptyState))]
    private string? _loadErrorMessage;

    [ObservableProperty]
    private string? _refreshErrorMessage;

    [ObservableProperty]
    [NotifyCanExecuteChangedFor(nameof(LoadOlderCommand))]
    private string? _loadOlderErrorMessage;

    [ObservableProperty]
    private string? _actionErrorMessage;

    [ObservableProperty]
    [NotifyPropertyChangedFor(nameof(ShowEndOfFeed))]
    [NotifyCanExecuteChangedFor(nameof(LoadOlderCommand))]
    private bool _reachedEnd;

    public TimelineViewModel(ITimelineProvider provider, ICredentialStore credentials, ILinkOpener links, IClipboardService clipboard, TimeProvider time, ILogger<TimelineViewModel> logger)
    {
        _provider = provider;
        _credentials = credentials;
        _links = links;
        _clipboard = clipboard;
        _time = time;
        _logger = logger;
    }

    /// <summary>Raised when revealed posts should be brought into view.</summary>
    public event EventHandler? ScrollToTopRequested;

    public ObservableCollection<TimelineItemViewModel> Items { get; } = [];

    public bool ShowSignInHint => !IsSignedIn;

    public bool ShowEmptyState => IsSignedIn && _buffer.HasLoaded && !IsLoading && LoadErrorMessage is null && Items.Count == 0;

    public bool ShowEndOfFeed => ReachedEnd && Items.Count > 0;

    /// <summary>Called whenever the page is shown: re-checks sign-in, clears a signed-out
    /// timeline, and loads if nothing has loaded yet.</summary>
    public async Task ActivateAsync(CancellationToken cancellationToken)
    {
        IsSignedIn = _credentials.TryGet(CredentialAccounts.Default) is not null;
        if (!IsSignedIn)
        {
            if (_buffer.HasLoaded || Items.Count > 0)
            {
                _buffer.Clear();
                Items.Clear();
                SyncFromBuffer();
            }

            return;
        }

        if (!_buffer.HasLoaded && !IsLoading)
        {
            await LoadAsync(cancellationToken).ConfigureAwait(true);
        }
    }

    /// <summary>Re-computes every item's relative time; called on each poll tick.</summary>
    public void UpdateRelativeTimes()
    {
        var now = _time.GetLocalNow();
        foreach (var item in Items)
        {
            item.UpdateTime(now);
        }
    }

    [RelayCommand]
    private async Task LoadAsync(CancellationToken cancellationToken)
    {
        IsLoading = true;
        LoadErrorMessage = null;
        try
        {
            var page = await _provider.GetFeedAsync(FeedKind.Timeline, PageRequest.Newest(), cancellationToken).ConfigureAwait(true);
            _buffer.Reset(page);
            ReplaceItems();
            _schedule.RecordSuccess();
        }
        catch (OperationCanceledException) when (cancellationToken.IsCancellationRequested)
        {
        }
        catch (Exception ex)
        {
            _schedule.RecordFailure((ex as MicropubException)?.RetryAfter);
            LoadErrorMessage = ComposerErrorMessages.Describe(ex);
            _logger.LogWarning(ex, "Loading the timeline failed");
        }
        finally
        {
            IsLoading = false;
            SyncFromBuffer();
        }
    }

    private bool CanLoadOlder() => !IsLoading && !IsLoadingOlder && !ReachedEnd && LoadOlderErrorMessage is null && _buffer.OldestId is not null;

    [RelayCommand(CanExecute = nameof(CanLoadOlder))]
    private async Task LoadOlderAsync(CancellationToken cancellationToken)
    {
        var oldestId = _buffer.OldestId!;
        var generation = _buffer.Generation;
        IsLoadingOlder = true;
        try
        {
            var page = await _provider.GetFeedAsync(FeedKind.Timeline, PageRequest.OlderThan(oldestId), cancellationToken).ConfigureAwait(true);
            if (generation != _buffer.Generation)
            {
                return; // The list was replaced while this was in flight; the page belongs to the old one.
            }

            var now = _time.GetLocalNow();
            foreach (var item in _buffer.AppendOlder(page))
            {
                Items.Add(CreateItem(item, now));
            }
        }
        catch (OperationCanceledException) when (cancellationToken.IsCancellationRequested)
        {
        }
        catch (Exception ex)
        {
            LoadOlderErrorMessage = ComposerErrorMessages.Describe(ex);
            _logger.LogWarning(ex, "Loading older posts failed");
        }
        finally
        {
            IsLoadingOlder = false;
            SyncFromBuffer();
        }
    }

    [RelayCommand]
    private async Task RetryLoadOlderAsync()
    {
        LoadOlderErrorMessage = null;
        if (LoadOlderCommand.CanExecute(null))
        {
            await LoadOlderCommand.ExecuteAsync(null).ConfigureAwait(true);
        }
    }

    [RelayCommand]
    private async Task RefreshAsync(CancellationToken cancellationToken)
    {
        if (!_buffer.HasLoaded)
        {
            await LoadAsync(cancellationToken).ConfigureAwait(true);
            return;
        }

        IsRefreshing = true;
        try
        {
            await FetchNewerAsync(cancellationToken).ConfigureAwait(true);
            if (RevealPending())
            {
                ScrollToTopRequested?.Invoke(this, EventArgs.Empty);
            }
        }
        catch (OperationCanceledException) when (cancellationToken.IsCancellationRequested)
        {
        }
        catch (Exception ex)
        {
            RecordRefreshFailure(ex);
        }
        finally
        {
            IsRefreshing = false;
            SyncFromBuffer();
        }
    }

    // Fetches posts newer than everything seen into the buffer's Pending; never touches Items.
    private async Task FetchNewerAsync(CancellationToken cancellationToken)
    {
        var generation = _buffer.Generation;
        var request = _buffer.NewestId is { } newest ? PageRequest.NewerThan(newest) : PageRequest.Newest();
        var page = await _provider.GetFeedAsync(FeedKind.Timeline, request, cancellationToken).ConfigureAwait(true);
        if (generation != _buffer.Generation)
        {
            return;
        }

        _buffer.AddNewer(page, request.Count);
        _schedule.RecordSuccess();
        RefreshErrorMessage = null;
    }

    private void RecordRefreshFailure(Exception ex)
    {
        _schedule.RecordFailure((ex as MicropubException)?.RetryAfter);
        RefreshErrorMessage = ComposerErrorMessages.Describe(ex);
        _logger.LogWarning(ex, "Checking for new posts failed");
    }

    // Returns true when anything was revealed.
    private bool RevealPending()
    {
        var result = _buffer.RevealPending();
        if (result.Revealed.Count == 0)
        {
            return false;
        }

        if (result.ReplacedAll)
        {
            ReplaceItems();
        }
        else
        {
            var now = _time.GetLocalNow();
            for (var i = result.Revealed.Count - 1; i >= 0; i--)
            {
                Items.Insert(0, CreateItem(result.Revealed[i], now));
            }
        }

        return true;
    }

    private void ReplaceItems()
    {
        var now = _time.GetLocalNow();
        Items.Clear();
        foreach (var item in _buffer.Items)
        {
            Items.Add(CreateItem(item, now));
        }
    }

    private void SyncFromBuffer()
    {
        ReachedEnd = _buffer.ReachedEnd;
        OnPropertyChanged(nameof(ShowEmptyState));
        OnPropertyChanged(nameof(ShowEndOfFeed));
        LoadOlderCommand.NotifyCanExecuteChanged();
    }

    private TimelineItemViewModel CreateItem(TimelineItem item, DateTimeOffset now)
        => new(item, now, _links, _clipboard, message => ActionErrorMessage = message);
}
```

```csharp
    [ObservableProperty]
    [NotifyPropertyChangedFor(nameof(ShowPendingPill), nameof(PendingPillText), nameof(PendingPillAutomationName))]
    private int _pendingCount;

    [ObservableProperty]
    [NotifyPropertyChangedFor(nameof(PendingPillText), nameof(PendingPillAutomationName))]
    private bool _pendingHasGap;

    public bool ShowPendingPill => PendingCount > 0;

    public string PendingPillText => PendingHasGap
        ? $"{PendingCount}+ new posts"
        : PendingCount == 1 ? "1 new post" : $"{PendingCount} new posts";

    public string PendingPillAutomationName => $"{PendingPillText}. Show them";

    /// <summary>How long the poll loop waits next (SPEC.md §6.4 back-off included).</summary>
    public TimeSpan NextPollDelay => _schedule.NextDelay;

    [RelayCommand]
    private void ShowPending()
    {
        if (RevealPending())
        {
            ScrollToTopRequested?.Invoke(this, EventArgs.Empty);
        }

        SyncFromBuffer();
    }

    /// <summary>One poll: fetches newer posts into the pending set. Never touches
    /// <see cref="Items"/>, except on an empty list, where there's nothing to disturb. Before a
    /// first successful load it performs the load instead, so launching offline recovers by itself.
    /// Failures show <see cref="RefreshErrorMessage"/> and back off; only the caller's own
    /// cancellation escapes.</summary>
    public async Task PollOnceAsync(CancellationToken cancellationToken)
    {
        if (_credentials.TryGet(CredentialAccounts.Default) is null || IsLoading || IsRefreshing)
        {
            return;
        }

        if (!_buffer.HasLoaded)
        {
            await LoadAsync(cancellationToken).ConfigureAwait(true);
            return;
        }

        try
        {
            await FetchNewerAsync(cancellationToken).ConfigureAwait(true);
            if (Items.Count == 0)
            {
                RevealPending();
            }
        }
        catch (OperationCanceledException) when (cancellationToken.IsCancellationRequested)
        {
            throw;
        }
        catch (Exception ex)
        {
            RecordRefreshFailure(ex);
        }
        finally
        {
            SyncFromBuffer();
            UpdateRelativeTimes();
        }
    }

    /// <summary>Polls on <see cref="NextPollDelay"/> until <paramref name="cancellationToken"/>
    /// is cancelled, then completes normally. <see cref="PollOnceAsync"/> handles every other
    /// failure itself.</summary>
    public async Task RunPollingAsync(CancellationToken cancellationToken)
    {
        try
        {
            while (true)
            {
                await Task.Delay(_schedule.NextDelay, _time, cancellationToken).ConfigureAwait(true);
                await PollOnceAsync(cancellationToken).ConfigureAwait(true);
            }
        }
        catch (OperationCanceledException) when (cancellationToken.IsCancellationRequested)
        {
        }
    }
```

```csharp
using Microsoft.UI.Text;
using Microsoft.UI.Xaml;
using Microsoft.UI.Xaml.Controls;
using Microsoft.UI.Xaml.Documents;
using Microsoft.UI.Xaml.Media;

using Transom.Core.Rendering;

namespace Transom.App.Rendering;

/// <summary>Draws <see cref="RichContent"/> into a <see cref="RichTextBlock"/>. It sets no
/// colours: text, links, quotes and code inherit theme brushes, so a light/dark or high-contrast
/// switch while running re-colours everything (M-13). Quotes are indented and italic; list
/// items get "• " / "1. " markers.</summary>
internal static class RichContentRenderer
{
    private const double IndentPerLevel = 16;
    private static readonly FontFamily CodeFont = new("Cascadia Mono, Consolas");

    public static void Render(RichTextBlock target, RichContent content)
    {
        target.Blocks.Clear();
        foreach (var block in content.Blocks)
        {
            AddBlock(target, block, level: 0, quoted: false, marker: null);
        }
    }

    private static void AddBlock(RichTextBlock target, RichBlock block, int level, bool quoted, string? marker)
    {
        switch (block)
        {
            case RichParagraph paragraph:
                var p = NewParagraph(level, quoted);
                if (marker is not null)
                {
                    p.Inlines.Add(new Run { Text = marker });
                }

                AddInlines(p.Inlines, paragraph.Inlines);
                target.Blocks.Add(p);
                break;
            case RichQuote quote:
                foreach (var inner in quote.Blocks)
                {
                    AddBlock(target, inner, level + 1, quoted: true, marker: null);
                }
                break;
            case RichList list:
                for (var i = 0; i < list.Items.Count; i++)
                {
                    string? itemMarker = list.Ordered ? $"{i + 1}. " : "• ";
                    var item = list.Items[i];
                    if (item.Count == 0 || item[0] is not RichParagraph)
                    {
                        // The marker needs a paragraph to sit in; give it its own line.
                        var markerOnly = NewParagraph(level + 1, quoted);
                        markerOnly.Inlines.Add(new Run { Text = itemMarker });
                        target.Blocks.Add(markerOnly);
                        itemMarker = null;
                    }

                    for (var j = 0; j < item.Count; j++)
                    {
                        AddBlock(target, item[j], level + 1, quoted, j == 0 ? itemMarker : null);
                    }
                }
                break;
            case RichCodeBlock code:
                var c = NewParagraph(level, quoted);
                c.FontFamily = CodeFont;
                c.Inlines.Add(new Run { Text = code.Text });
                target.Blocks.Add(c);
                break;
        }
    }

    private static Paragraph NewParagraph(int level, bool quoted)
    {
        var paragraph = new Paragraph { Margin = new Thickness(level * IndentPerLevel, 0, 0, 8) };
        if (quoted)
        {
            paragraph.FontStyle = Windows.UI.Text.FontStyle.Italic;
        }

        return paragraph;
    }

    private static void AddInlines(InlineCollection target, IReadOnlyList<RichInline> inlines)
    {
        foreach (var inline in inlines)
        {
            switch (inline)
            {
                case RichText text:
                    target.Add(Styled(text));
                    break;
                case RichLineBreak:
                    target.Add(new LineBreak());
                    break;
                case RichLink link:
                    // NavigateUri: WinUI launches the default browser itself, and the link is
                    // keyboard- and Narrator-reachable. The parser guarantees absolute http(s) and
                    // no nested links. M4 swaps this for a routed Click to open @-mentions in-app.
                    var hyperlink = new Hyperlink { NavigateUri = new Uri(link.Href) };
                    AddInlines(hyperlink.Inlines, link.Inlines);
                    target.Add(hyperlink);
                    break;
            }
        }
    }

    private static Run Styled(RichText text)
    {
        var run = new Run { Text = text.Text };
        if (text.Style.HasFlag(RichStyle.Bold))
        {
            run.FontWeight = FontWeights.SemiBold;
        }
        if (text.Style.HasFlag(RichStyle.Italic))
        {
            run.FontStyle = Windows.UI.Text.FontStyle.Italic;
        }
        if (text.Style.HasFlag(RichStyle.Code))
        {
            run.FontFamily = CodeFont;
        }

        return run;
    }
}
```

```csharp
/// <summary><c>rendering:RichTextContent.Content="{x:Bind Content}"</c> on a RichTextBlock renders
/// it. ListView recycles containers, so every change re-renders from scratch.</summary>
public static class RichTextContent
{
    public static readonly DependencyProperty ContentProperty = DependencyProperty.RegisterAttached(
        "Content", typeof(RichContent), typeof(RichTextContent), new PropertyMetadata(null, OnContentChanged));

    public static RichContent? GetContent(DependencyObject element) => (RichContent?)element.GetValue(ContentProperty);

    public static void SetContent(DependencyObject element, RichContent? value) => element.SetValue(ContentProperty, value);

    private static void OnContentChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
    {
        if (d is not RichTextBlock block)
        {
            return;
        }

        try
        {
            RichContentRenderer.Render(block, e.NewValue as RichContent ?? RichContent.Empty);
        }
        catch (Exception ex)
        {
            // A post that can't be drawn must not take the list down with it (Review Focus #4).

            block.Blocks.Clear();
            var paragraph = new Paragraph();
            paragraph.Inlines.Add(new Run { Text = "This post couldn't be displayed. Use Open in browser." });
            block.Blocks.Add(paragraph);
        }
    }
}
```

```csharp
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Logging;
using Microsoft.UI.Xaml;
using Microsoft.UI.Xaml.Controls;
using Microsoft.UI.Xaml.Media;
using Microsoft.UI.Xaml.Media.Imaging;

using Transom.App.Services;

namespace Transom.App.Rendering;

/// <summary>
/// <c>rendering:CachedImage.Url="{x:Bind AvatarUrl}"</c> on an <see cref="Image"/> or
/// <see cref="PersonPicture"/> loads through <see cref="IImageCache"/>. Null, empty, whitespace or
/// non-http URLs mean "no image" (M1's crash shape): the Image stays empty over its placeholder,
/// and PersonPicture shows initials. Review Focus #7: on every change the old image is cleared
/// first, and a download that finishes after the container was recycled for another post is
/// dropped, so no post ever shows another post's picture.
/// </summary>
public static class CachedImage
{
    public static readonly DependencyProperty UrlProperty = DependencyProperty.RegisterAttached(
        "Url", typeof(string), typeof(CachedImage), new PropertyMetadata(null, OnUrlChanged));

    public static readonly DependencyProperty DecodePixelWidthProperty = DependencyProperty.RegisterAttached(
        "DecodePixelWidth", typeof(int), typeof(CachedImage), new PropertyMetadata(0));

    public static string? GetUrl(DependencyObject element) => (string?)element.GetValue(UrlProperty);

    public static void SetUrl(DependencyObject element, string? value) => element.SetValue(UrlProperty, value);

    public static int GetDecodePixelWidth(DependencyObject element) => (int)element.GetValue(DecodePixelWidthProperty);

    public static void SetDecodePixelWidth(DependencyObject element, int value) => element.SetValue(DecodePixelWidthProperty, value);

    private static async void OnUrlChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
    {
        var url = e.NewValue as string;
        try
        {
            SetSource(d, null);
            if (string.IsNullOrWhiteSpace(url))
            {
                return;
            }

            var local = await App.Host.Services.GetRequiredService<IImageCache>().GetLocalUriAsync(url, CancellationToken.None);
            if (!string.Equals(GetUrl(d), url, StringComparison.Ordinal) || local is null)
            {
                return;
            }

            var bitmap = new BitmapImage { DecodePixelType = DecodePixelType.Logical };
            if (GetDecodePixelWidth(d) is > 0 and var width)
            {
                bitmap.DecodePixelWidth = width;
            }

            bitmap.UriSource = new Uri(local);
            SetSource(d, bitmap);
        }
        catch (Exception ex)
        {
            // Rule 12: this is an async void callback; nothing may escape it. A failed image is a
            // placeholder, not an error the user can act on, so log it.
            App.Host.Services.GetRequiredService<ILogger<Image>>().LogWarning(ex, "Showing image {Url} failed", url);
        }
    }

    private static void SetSource(DependencyObject d, ImageSource? source)
    {
        switch (d)
        {
            case Image image:
                image.Source = source;
                break;
            case PersonPicture picture:
                picture.ProfilePicture = source;
                break;
        }
    }
}
```

The decode width is read after the await, so XAML attribute order doesn't matter. Decoding at
display size is what keeps 200+ posts of photos within the memory budget (M-14).

```csharp
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Logging;
using Microsoft.UI.Xaml;
using Microsoft.UI.Xaml.Automation;
using Microsoft.UI.Xaml.Controls;
using Microsoft.UI.Xaml.Input;
using Microsoft.UI.Xaml.Media;

using Transom.App.Services;
using Transom.App.ViewModels;

namespace Transom.App.Views;

public sealed partial class TimelinePage : Page
{
    private readonly ILogger<TimelinePage> _logger = App.Host.Services.GetRequiredService<ILogger<TimelinePage>>();
    private readonly CancellationTokenSource _polling = new();
    private ScrollViewer? _scrollViewer;
    private bool _pollingStarted;

    public TimelineViewModel ViewModel { get; }

    public TimelinePage()
    {
        ViewModel = App.Host.Services.GetRequiredService<TimelineViewModel>();
        InitializeComponent();
        ViewModel.ScrollToTopRequested += (_, _) => _scrollViewer?.ChangeView(null, 0, null, disableAnimation: true);
        // A first page shorter than the viewport never scrolls, so ViewChanged never fires; check
        // again whenever the list changes (M-2's tall-window case).
        ViewModel.Items.CollectionChanged += (_, _) => DispatcherQueue.TryEnqueue(LoadOlderIfNearBottom);
        Loaded += Page_Loaded;
    }

    // NavigationCacheMode="Required" keeps this instance, so Loaded fires on every return to the
    // page: re-check sign-in (Settings may have changed it) and start polling once.
    private async void Page_Loaded(object sender, RoutedEventArgs e)
    {
        try
        {
            await ViewModel.ActivateAsync(CancellationToken.None);
            if (!_pollingStarted)
            {
                _pollingStarted = true;
                _ = RunPollingAsync();
            }
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Activating the timeline failed");
            ViewModel.RefreshErrorMessage = ComposerErrorMessages.Describe(ex);
        }
    }

    // RunPollingAsync only ends by cancellation; anything else is a bug that would silently stop
    // new posts arriving (Rule 11), so say so.
    private async Task RunPollingAsync()
    {
        try
        {
            await ViewModel.RunPollingAsync(_polling.Token);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "The timeline poll loop stopped");
            ViewModel.RefreshErrorMessage = "Stopped checking for new posts. Use Refresh (F5) to check manually.";
        }
    }

    private void RefreshAccelerator_Invoked(KeyboardAccelerator sender, KeyboardAcceleratorInvokedEventArgs args)
    {
        args.Handled = true;
        if (ViewModel.RefreshCommand.CanExecute(null))
        {
            ViewModel.RefreshCommand.Execute(null);
        }
    }

    private void TimelineList_Loaded(object sender, RoutedEventArgs e)
    {
        if (_scrollViewer is not null)
        {
            return;
        }

        _scrollViewer = FindDescendant<ScrollViewer>(TimelineList);
        if (_scrollViewer is null)
        {
            // Rule 11: without this, infinite scroll would silently never trigger.
            _logger.LogError("TimelineList has no ScrollViewer; older posts can't load on scroll");
            ViewModel.LoadOlderErrorMessage = "Couldn't set up scrolling for older posts.";
            return;
        }

        _scrollViewer.ViewChanged += (_, _) => LoadOlderIfNearBottom();
    }

    // Starts loading within two screens of the bottom. LoadOlderCommand.CanExecute is the guard:
    // false while loading, at the end, or after a failure until Retry (Review Focus #1 and #5).
    private void LoadOlderIfNearBottom()
    {
        if (_scrollViewer is not { } sv || !ViewModel.LoadOlderCommand.CanExecute(null))
        {
            return;
        }

        if (sv.ScrollableHeight - sv.VerticalOffset <= sv.ViewportHeight * 2)
        {
            ViewModel.LoadOlderCommand.Execute(null);
        }
    }

    // ListViewItem's accessible name comes from here: x:Bind can't reach the container.
    // It's set on every (re)use, so recycled containers never keep another post's name.
    private void TimelineList_ContainerContentChanging(ListViewBase sender, ContainerContentChangingEventArgs args)
    {
        if (args.Item is TimelineItemViewModel item)
        {
            AutomationProperties.SetName(args.ItemContainer, item.AutomationName);
        }
    }

    // Tag, not DataContext: x:Bind never sets DataContext (CLAUDE.md Style).
    private async void ImageThumbnail_Click(object sender, RoutedEventArgs e)
    {
        try
        {
            if (((FrameworkElement)sender).Tag is not TimelineImageViewModel image)
            {
                ViewModel.ActionErrorMessage = "Couldn't open that image. Please try again.";
                return;
            }

            await ShowImageViewerAsync(image);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Opening the image viewer failed");
            ViewModel.ActionErrorMessage = ComposerErrorMessages.Describe(ex);
        }
    }

    // Task 11 replaces this with the viewer dialog.
    private Task ShowImageViewerAsync(TimelineImageViewModel image)
        => ViewModel.Items.FirstOrDefault(i => i.Images.Contains(image))?.OpenInBrowserCommand.ExecuteAsync(null) ?? Task.CompletedTask;

    private static T? FindDescendant<T>(DependencyObject root) where T : DependencyObject
    {
        for (var i = 0; i < VisualTreeHelper.GetChildrenCount(root); i++)
        {
            var child = VisualTreeHelper.GetChild(root, i);
            if (child is T match)
            {
                return match;
            }

            if (FindDescendant<T>(child) is { } nested)
            {
                return nested;
            }
        }

        return null;
    }
}
```

- [ ] **Step 1: Implement the viewer**

A `ContentDialog` sized to the window. WinUI caps dialogs at 548 px wide unless
`ContentDialogMaxWidth`/`MaxHeight` are overridden in the dialog's own resources. It shows the
full-size image (decoded at the image's natural size), the alt text below it, "Previous"/"Next"
for multi-photo posts (Left/Right arrows too), "Open original" (primary) and "Close" (Esc).

```csharp
    private async Task ShowImageViewerAsync(TimelineImageViewModel start)
    {
        var current = start;
        var image = new Image { Stretch = Microsoft.UI.Xaml.Media.Stretch.Uniform, MaxHeight = XamlRoot.Size.Height * 0.7 };
        var alt = new TextBlock { TextWrapping = TextWrapping.Wrap, IsTextSelectionEnabled = true, MaxWidth = XamlRoot.Size.Width * 0.8 };
        var position = new TextBlock { Foreground = (Microsoft.UI.Xaml.Media.Brush)Application.Current.Resources["TextFillColorSecondaryBrush"] };
        var previous = new Button { Content = "Previous", Visibility = start.Total > 1 ? Visibility.Visible : Visibility.Collapsed };
        var next = new Button { Content = "Next", Visibility = start.Total > 1 ? Visibility.Visible : Visibility.Collapsed };
        AutomationProperties.SetName(previous, "Previous image");
        AutomationProperties.SetName(next, "Next image");

        void Show(TimelineImageViewModel shown)
        {
            current = shown;
            Rendering.CachedImage.SetUrl(image, shown.Url);
            AutomationProperties.SetName(image, shown.AltTextOrPlaceholder);
            alt.Text = shown.AltTextOrPlaceholder;
            position.Text = shown.Total > 1 ? $"{shown.Position} of {shown.Total}" : string.Empty;
            previous.IsEnabled = shown.Position > 1;
            next.IsEnabled = shown.Position < shown.Total;
        }

        previous.Click += (_, _) => Show(current.Siblings[current.Position - 2]);
        next.Click += (_, _) => Show(current.Siblings[current.Position]);

        var content = new StackPanel { Spacing = 12 };
        content.Children.Add(image);
        content.Children.Add(alt);
        var navigation = new StackPanel { Orientation = Orientation.Horizontal, Spacing = 8 };
        navigation.Children.Add(previous);
        navigation.Children.Add(position);
        navigation.Children.Add(next);
        content.Children.Add(navigation);

        var dialog = new ContentDialog
        {
            XamlRoot = XamlRoot,
            Title = "Image",
            Content = content,
            PrimaryButtonText = "Open original",
            CloseButtonText = "Close",
            DefaultButton = ContentDialogButton.Close,
        };
        dialog.Resources["ContentDialogMaxWidth"] = XamlRoot.Size.Width * 0.9;
        dialog.Resources["ContentDialogMaxHeight"] = XamlRoot.Size.Height * 0.95;
        dialog.KeyDown += (_, e) =>
        {
            if (e.Key == Windows.System.VirtualKey.Left && previous.IsEnabled)
            {
                Show(current.Siblings[current.Position - 2]);
                e.Handled = true;
            }
            else if (e.Key == Windows.System.VirtualKey.Right && next.IsEnabled)
            {
                Show(current.Siblings[current.Position]);
                e.Handled = true;
            }
        };

        Show(start);
        if (await dialog.ShowAsync() == ContentDialogResult.Primary)
        {
            var opened = await App.Host.Services.GetRequiredService<ILinkOpener>().OpenAsync(new Uri(current.Url), CancellationToken.None);
            if (!opened)
            {
                ViewModel.ActionErrorMessage = "Couldn't open the image in your browser.";
            }
        }
    }
```

The secondary brush is looked up once, when the dialog opens. That's fine for a transient dialog,
though it wouldn't follow a theme switch made while the dialog is open. The caller, `ImageThumbnail_Click`, already
wraps this in Rule 12's try/catch. Only one dialog can be open at a time, and the viewer is modal,
so no second dialog can start behind it (the M2 overlap came from background completions, which
this page doesn't have).
